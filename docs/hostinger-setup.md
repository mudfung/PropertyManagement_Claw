# ☁️ Hostinger 1-Click Setup (Recommended)

This guide shows how to deploy OpenClaw using Hostinger’s prebuilt container.

---

## 🚀 Why Use Hostinger 1-Click?

- No Docker or Node setup required  
- Preconfigured OpenClaw container  
- Fast deployment (under 5 minutes)  
- Managed infrastructure (auto updates + security)  

👉 Hostinger handles all backend setup for you  

---

## 1. Create OpenClaw Instance

Go to: Hostinger

### Steps:

1. Select **1-Click OpenClaw**  
2. Click **Get OpenClaw**  
3. Choose plan and region  
4. Complete checkout  

---

## 2. Configure Your AI Agent

During setup, Hostinger will ask:

### 🔑 AI Provider

Choose one:

- Built-in (nexos.ai credits)  
- OR your own API key (OpenAI / Anthropic)  

---

### 💬 Communication Channel

Choose:

- Telegram (recommended)  
- WhatsApp  

---

## 3. Access Your OpenClaw Dashboard

1. Go to **hPanel → OpenClaw**  
2. Click **Access Application**  
3. Open your dashboard  

---

## 4. Pair Your Telegram Bot

1. Open Telegram  
2. Search your bot  
3. Send message: `start`  

👉 You will receive a pairing code  

Approve it inside OpenClaw
