🏠 OpenClaw PMO Agent – Property Management Automation
  Automate your entire property finance workflow using AI.

🚀 What This Does
  The PMO (Property Management Officer) agent:
    📄 Reads invoices using OCR
    🗂 Organises files automatically
    📊 Updates Google Sheets in real time
    💰 Tracks expenses and rental income
    📈 Generates P&L reports
    
⚡ 2-Second Workflow
  Send invoice via Telegram
  AI processes it instantly
  File stored + Google Sheet updated
  Payment tracked automatically

📊 Features
  Multi-property support
  Smart file naming system
  Expense + rental income tracking
  Automated P&L calculation
  Google Sheets integration
